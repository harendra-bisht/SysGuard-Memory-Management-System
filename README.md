# 🖥️ System Health Dashboard

## Project Overview

System Health Dashboard is a web-based application developed to monitor and visualize the overall health of a computer system through an interactive dashboard. The application provides a clean and user-friendly interface where users can view important system information such as CPU usage, memory usage, disk status, network activity, and running processes.

The main objective of this project is to simplify system monitoring by presenting all essential information in one place. It is designed as an Operating Systems project and can be extended to display real-time system statistics using a Python Flask backend.

## Installation

Clone the repository:

```bash
git clone https://github.com/harendra-bisht/System-Health-Dashboard.git
```

Move into the project folder:

```bash
cd System-Health-Dashboard
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
